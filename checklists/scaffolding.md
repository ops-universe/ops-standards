# Scaffolding acceptance checklist

- [ ] Product brief, business problem, differentiation, acceptance criteria and non-goals.
- [ ] Approved license and complete community files.
- [ ] Project metadata, repo topics and relevant issue forms.
- [ ] Working vertical slice with failure tests, trusted policy and synthetic data.
- [ ] ADRs, threat model, deployment and rollback guidance.
- [ ] Website: accessible navigation, themes, search, project-specific hero, responsive layout, SEO and clean routes; verify root and subpath builds.
- [ ] Lockfiles, CI evidence tied to commit, no secrets, browser checks where applicable.
- [ ] Wiki/Discussions publication verified separately from source files.
- [ ] Maintainer-approved PR and release gate report.

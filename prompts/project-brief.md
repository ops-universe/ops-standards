# New project invocation

Use the master prompt and engineering, design and release standards from a pinned revision of ops-standards. Inputs: project name, owner, business problem, target users, target URL, license, scope, constraints. Inspect existing state; use ops-template; implement one testable vertical slice; publish a focused PR with evidence and blockers. No unapproved transfer or DNS changes. Mark missing tools explicitly. Never claim deployment or community setup without verification.
